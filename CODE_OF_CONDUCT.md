# Código de conduta

Queremos uma comunidade acolhedora, principalmente por ser um projeto voltado a crianças e adolescentes.

## Esperamos

- Respeito e educação com todas as pessoas.
- Críticas ao código e às ideias, nunca às pessoas.
- Linguagem adequada para todas as idades em issues, commits e conteúdo de exemplo.

## Não toleramos

- Assédio, discriminação ou ofensas.
- Conteúdo sexual, violento ou impróprio para menores.
- Publicar dados pessoais de terceiros.

## Aplicação

Comportamentos que violem estas regras podem resultar em remoção de comentários, bloqueio de contribuições ou banimento do projeto. Para denunciar, abra uma issue privada ou contate a pessoa mantenedora.

Este texto é inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/).
