# Como contribuir

Obrigado por querer ajudar! Este guia explica o fluxo básico.

## Fluxo

1. Faça um fork (ou crie uma branch, se tiver acesso).
2. Crie uma branch curta por tarefa: `feat/jogo-forca`, `fix/login-responsavel`, `docs/readme`.
3. Faça commits pequenos usando [Conventional Commits](https://www.conventionalcommits.org/pt-br/):
   - `feat: adiciona jogo da forca`
   - `fix: corrige cálculo de XP`
   - `docs: atualiza README`
4. Abra um Pull Request para a `main` descrevendo o que mudou e por quê.

## Antes de abrir o PR

- Rode `npm test`.
- Teste o app no celular (ou no modo dispositivo do navegador).
- Lembre que o público são crianças: evite linguagem inadequada, pressão excessiva (rankings, notificações insistentes) e coleta desnecessária de dados.

## Ideias e bugs

Use as [issues](../../issues) com os modelos disponíveis.
